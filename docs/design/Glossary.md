# Glossary

> **Purpose:** Definitions of the game's themed vocabulary and system terms.
> **Owner:** Franco Fusaro · **Status:** Living · **Last Updated:** 2026-07-27
> **Related:** [Vision](Vision.md), [CoreLoop](CoreLoop.md), [gameplay/Abilities](gameplay/Abilities.md)

| Term | Meaning |
|------|--------|
| **Swap** | The single core verb — instant control-flip between the two cats. |
| **Leadership** | Which cat is currently active/in control. Shifts between Orange and Tuxedo via swap; the non-leading cat stays present, not absent. See [CoreLoop — Swap Philosophy](CoreLoop.md#swap-philosophy). |
| **Recall / Toss** | Separate lower-frequency verb: summon or hurl the partner. |
| **Zoomies** | Orange's flow verb — dash / dash-cancel / wall-jump / pounce. |
| **Loaf** | Tuxedo's puzzle verb — plants into an immovable platform/anchor. |
| **The Flop** | Tuxedo's ground-pound AoE stun (combat). |
| **Wall-cling** | Orange's puzzle verb — cling/climb walls, squeeze into gaps. |
| **Teleport-recover** | Inactive cat warps to the leader's last safe spot during flow. |
| **Puzzle room** | Enclosed, exit-locked room where teleport-recover is disabled. |
| **Arena** | A boss fight staged as a puzzle room. |
| **Downed** | A cat at 0 HP — not dead; revivable by the other cat. |
